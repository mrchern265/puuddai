# Supabase seeds

เนื้อหาบทเรียนของ PuudDai เก็บอยู่ในฐานข้อมูล Supabase (ตาราง `units`, `lessons`,
`scenarios`) ไม่ได้ฝังอยู่ในโค้ด โฟลเดอร์นี้เก็บสคริปต์ SQL สำหรับเพิ่ม/แก้ไขเนื้อหา
เพื่อให้เวอร์ชันของเนื้อหาถูกติดตามใน git ไปด้วย

## ไฟล์

- `immigration_unit.sql` — ยูนิต **"ที่ด่านตรวจคนเข้าเมือง (ตม.)"** สำหรับฝึกภาษาอังกฤษ
  เวลาไปเที่ยวต่างประเทศแล้วเจ้าหน้าที่ ตม. ถามคำถาม ประกอบด้วย
  - 3 บทเรียน: คำศัพท์พื้นฐาน · ตอบคำถามที่ ตม. ถามบ่อย · ประโยคช่วยชีวิตเมื่อฟังไม่ทัน
  - 1 สถานการณ์ฝึกสนทนากับ AI: "ผ่านด่าน ตม. ที่สนามบิน"

## วิธีรัน

Supabase Dashboard → SQL Editor → วางเนื้อหาไฟล์แล้วกด **Run**

หรือผ่าน psql:

```bash
psql "$DATABASE_URL" -f supabase/seeds/immigration_unit.sql
```

สคริปต์จะต่อท้ายเป็นยูนิตถัดไปโดยอัตโนมัติ (`order_index` = ค่าสูงสุดปัจจุบัน + 1)
รันซ้ำได้อย่างปลอดภัย — ถ้ามียูนิตชื่อเดียวกันอยู่แล้วจะข้ามให้ (กัน seed ซ้ำ)

โครงสร้าง `content_json` ของบทเรียนอ้างอิงจาก `LessonContent` ใน `src/types.ts`
